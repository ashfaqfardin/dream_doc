# assets/

Optional folder for your own source images.

Ready-to-use images are already in `inputs/`:
- `inputs/cat.jpg` — cat (Wikimedia Commons)
- `inputs/dog.jpg` — yellow Labrador (Wikimedia Commons)
- `inputs/car.jpg` — red Abarth sports car (Wikimedia Commons)
- `inputs/bottle.jpg` — glass bottle

To use a custom image, add it here and update the `source_image` path in the relevant config under `prompts/`.
