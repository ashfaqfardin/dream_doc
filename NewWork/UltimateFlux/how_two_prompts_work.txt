================================================================================


THE KEY INSIGHT
────────────────

  There is NO architectural change to FLUX.

  Two things are used:

  1.  Standard PyTorch batch dimension
      ─────────────────────────────────
      Passing prompt = ["A", "B"] to diffusers is identical to
      generating 2 images at once. The transformer processes
      both items with the same weights in a single forward pass.
      Both items have their own text conditioning driving Q/K/V.

  2.  Custom attention processor  (set_attn_processor)
      ───────────────────────────────────────────────────
      A standard HuggingFace hook that replaces the attention
      computation in all layers. At injection layers it reads
      K[0] and V[0] (source branch) and writes them into
      K[1] and V[1] (edit branch) before attention is computed.

      This is possible because both branches are in the same
      tensor — the batch dimension puts them side by side.


================================================================================


WHY THE SAME INITIAL NOISE IS CRITICAL
────────────────────────────────────────

  DIFFERENT noise:

    branch 0  →  cat forms top-left
    branch 1  →  cat forms bottom-right

    Injecting K[0] into branch 1 tells branch 1
    to attend top-left. But branch 1's latent is
    evolving bottom-right. They fight each other.
    Result: blurry / incoherent.

  SAME noise:

    Both branches evolve the same spatial layout.
    K[0] injected into branch 1 reinforces the
    same spatial structure. Edit prompt steers
    only the semantic content through Q and text.
    Result: coherent edit with preserved structure.
